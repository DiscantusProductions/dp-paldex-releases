# DP_Paldex — releases

Download the latest installer from the [Releases](../../releases) page.

**This repository holds releases only. There is no source code here**, and that
is deliberate: GitHub has no "private repository with public releases" mode, so
the source lives in a private repository and the built installers are published
here, where anyone can download them without an account, a token, or an
invitation.

## For the app

DP_Paldex checks this repository for updates. It needs no GitHub account and no
credentials to do so — earlier builds asked each user to paste a personal access
token, because releases were published to the private repository and private
release assets cannot be downloaded anonymously. That requirement is gone.

## Reporting a problem

Open **Settings → Diagnostics → Save a report** in the app. It writes a file
containing no licence key, no signature and no personal identifier, which is
safe to attach to an email or a forum post.
